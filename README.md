## 📖 Manuals forged

### 🌀 Manual of the turning fate — Churn Analytics with Uplift Modeling
> Finds the disciples who can still be swayed back to the sect — not just the ones flagged as leaving.
- Compared churn classifiers against three uplift models: XGBoost reached 0.9646 ROC-AUC, SoloModel led on uplift with 0.1708 Qini AUC
- Built a campaign ROI simulator (expected uplift × customer lifetime value vs. offer cost), defended with SHAP and Qini curves
- Shipped behind a FastAPI + PostgreSQL service with API-key auth, containerized via Docker Compose alongside a Streamlit dashboard
- *Repo not public yet — link goes here once it's pushed*

### 🧿 Scroll of a thousand answers — DocuMind AI (RAG)
> A spirit that has already read every manual in the library and answers before you finish the question.
- Full-stack RAG system — upload a PDF, ask in plain language, get grounded answers with source citations
- Retrieval pipeline: chunked PDF text → SentenceTransformer embeddings → FAISS index, paired with a local LLM (Ollama, phi3:mini) kept on a short context leash to cut hallucination

[View manual →](https://github.com/NaveenThankaswamy/DocuMind-AI-RAG)

### 🏮 Grand bazaar array — EcoStream-Lite
> Four storefronts, one admin formation, all watched over by spirit-messengers.
- Multi-tenant platform (React 19, Express, SQLite) — 4 independent storefronts sharing one admin layer
- LLMs via OpenRouter handle SEO copywriting, sentiment analysis, and smart customer replies; a React dashboard oversees cross-store analytics

[View manual →](https://github.com/NaveenThankaswamy/ECOSTREAM-LITE)

### 🍃 EcoFinds array — Rapr-odoo
